# Culturas Peruanas

Aplicación desarrollada en Swift y UIKit para el Laboratorio 7 del curso de Programación en Móviles Avanzado.

## Descripción

La aplicación permite conocer algunas culturas del Perú mediante una lista con imágenes. Al seleccionar una cultura, se muestra otra pantalla con su región, descripción e imagen.

## Tecnologías utilizadas

- Swift
- UIKit
- Storyboard
- Xcode

## Casos de uso

**CU01 - Ver culturas:** El usuario puede visualizar una lista de culturas peruanas con sus respectivas imágenes.

**CU02 - Seleccionar cultura:** El usuario puede elegir una cultura de la lista para consultar su información.

**CU03 - Consultar detalles:** La aplicación muestra el nombre, región, descripción e imagen de la cultura seleccionada.

**CU04 - Regresar a la lista:** El usuario puede volver a la pantalla principal para explorar otras culturas.

## Culturas incluidas

- Inca
- Moche
- Chavín
- Chimú
- Nazca

## Ejecución

1. Abrir `Tarea1.xcodeproj` en Xcode.
2. Seleccionar un simulador de iPhone.
3. Presionar `Command + R` para ejecutar.
